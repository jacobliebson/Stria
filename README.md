A high-performance, polyphonic resonator synthesizer built with C++ and the JUCE framework. This plugin utilizes custom-designed physical modeling DSP to simulate complex resonant structures. Key features include sample-accurate excitation processing, dynamic voice management, a sophisticated arpeggiator module, separate ADSR envelopes for the main and arpeggiator voices, and the ability to either use it as an effect on a live track or as a sample-driven synthesizer.
